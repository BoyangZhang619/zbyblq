# 课表生成器

一个现代化的课表管理和展示工具，可以将JSON格式的课表数据转换为美观的网页版课表，并支持下载为图片。

## 功能特性

✨ **主要功能：**

- 📤 支持上传JSON课表文件
- 📥 加载默认课表（从同源目录获取）
- 📅 按星期切换查看（周一至周日）
- 📊 纵轴为周数，横轴为12节课时
- 🎨 彩色课程卡片，支持多种配色方案
- ℹ️ 点击课程卡片查看详细信息
- 💾 下载课表为PNG图片
- 📱 响应式设计，支持移动设备
- 🔢 自动识别最大周数

## 使用方法

### 1. 加载默认课表

点击"📥 加载默认课表"按钮，系统会自动从同源目录加载 `课表_2025-2026-1_230200400_20260322.json` 文件。

### 2. 上传自定义课表

点击"📤 上传JSON文件"按钮，选择你的课表JSON文件进行上传。

### 3. 切换星期查看

课表加载后，会显示周一至周日的7个按钮。点击不同的日期按钮可以切换查看该天的课表，表格会自动更新显示该天的所有周次和课程。

### 4. 查看课程详情

点击任何课程卡片可以查看该课程的详细信息，包括：

- 课程名称
- 教师名称
- 教室位置
- 学分学时
- 周次安排
- 课程代码
- 开课单位
- 课程分类

### 5. 下载课表

点击"💾 下载为图片"按钮将当前显示的课表（当前选中的星期）下载为PNG格式的图片。

## 课表布局说明

### 表格结构

课表采用以下结构：

- **纵轴（左侧）**：显示第1周到最大周数的所有周次
- **横轴（顶部）**：显示12节课（包含时间和节次）
  - 1-2节：08:00-09:40
  - 3-4节：09:50-11:30
  - 5-6节：12:20-14:00
  - 7-8节：14:00-15:40
  - 9-10节：15:40-17:20
  - 11-12节：17:20-19:00

### 星期切换

在表格上方有7个按钮（周一至周日），点击不同按钮可以切换查看该天的完整课表。当前选中的星期会以高亮显示。

### 周次自动判断

系统会自动从JSON数据的 `SKZC` 字段（二进制周次表示）或 `ZCMC` 字段（文字周次表示）提取并计算最大周数。如果都没有找到，默认显示25周。

## JSON 文件格式要求

你的JSON文件应该遵循以下格式：

```json
{
  "datas": {
    "queryxskb": {
      "rows": [
        {
          "XM": "学生名称",
          "SKBJ": "班级名称",
          "XNXQDM_DISPLAY": "学期信息",
          "KCM": "课程名称",
          "SKJS": "教师名称",
          "JASMC": "教室位置",
          "SKXQ": 1,              // 星期几 (1=周一, 2=周二, ..., 5=周五)
          "KSJC": 1,              // 开始时间段 (1-12)
          "JSJC": 2,              // 课程节数 (持续多长时间)
          "XF": 4,                // 学分
          "XS": 64,               // 学时
          "ZCMC": "1-4周,6周",    // 周次安排
          "KCH": "课程代码",
          "KKDWDM_DISPLAY": "开课单位",
          "KCPYCCDM_DISPLAY": "课程分类"
        }
        // ... 更多课程
      ]
    }
  }
}
```

4. 绿色渐变 (`color-4`)
5. 黄粉色渐变 (`color-5`)
6. 蓝紫色渐变 (`color-6`)

## 常见问题

**Q: 为什么加载不了默认课表？**

A: 确保JSON文件在同一目录下，并且文件名完全相同。检查浏览器控制台的错误信息。

**Q: 上传后没有显示课程？**

A: 检查JSON文件格式是否正确，特别是 `datas.queryxskb.rows` 字段是否存在。

**Q: 下载图片失败？**

A: 这可能是网络问题或浏览器限制。尝试刷新页面或使用其他浏览器。
